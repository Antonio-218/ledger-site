# 轻账本 · 随手记账

一个手账风格的记账应用。全部功能装在一个 `轻账本.html` 文件里，双击就能用，数据只保存在你自己的浏览器里。

- **在线体验**：https://workbuddy.link/p/mGCQ8m8okHtyBPDoYE7cqt
- **本地运行**：直接用浏览器打开 `轻账本.html` 即可，无需安装任何东西

---

## 特性

- **单文件、零依赖**：HTML + CSS + 原生 JavaScript 全部写在一个文件里，不需要构建、不需要服务器、不联网也能用。
- **多账本隔离**：可以建多个账本（如「日常」「旅行」「家庭」），每个账本的记录、账户、统计完全独立。
- **纯本地存储**：数据存在浏览器 `localStorage`，不上传服务器。别人打开分享链接，只会得到一份全新的空白账本。
- **资产与流水联动**：日历里记一笔时会选择计入哪个账户，账户余额自动增减；也支持账户间转账、手动调整余额。
- **丰富的统计**：按周 / 月 / 年 / 自定义区间查看结余、收支趋势、占比环图、类目排行，并和上一周期对比。
- **可自定义分类**：支出、收入分类都能增删改，记账时分类网格固定 2 行 × 5 列、可翻页。
- **数据备份**：一键导出 / 导入备份，可手动载入示例数据体验图表。

---

## 界面与功能

应用分四个页面，底部导航（桌面端为左侧栏）切换：

### 📅 日历
- 月历视图，每天下方显示当天收入 / 支出小计，有记录的日期会高亮。
- 点某一天展开当天明细，底部有「＋ 在这一天记一笔」。
- 顶部可切换账本、翻看月份。

### 📊 统计
- 顶部「支出 / 收入」切换，右上角圆形时钟按钮选择统计周期：**按周 / 按月 / 按年 / 自定义**，选完弹层自动收起。
- 结余卡片：本期收入 − 支出，并显示与上一等长周期的对比。
- 趋势图：日 / 月粒度折线图，带峰值气泡。
- 占比概况：按分类着色的环形图，点击扇区会跳动一下；所有类目都会标注。
- 类目排行：点击某个类目就地展开该类目在本期的所有账单（可编辑 / 删除）。

### 💰 资产
- 净资产 / 总资产 / 负债概览，可展开资产趋势图，👁 按钮可一键隐藏金额。
- 账户列表按账本隔离；点账户进入详情，查看余额、备注与流水。
- 账户详情顶部有「⇄ 转账」和「＋ 记一笔」，流水支持按周 / 月 / 年 / 自定义筛选。
- 余额为负数即视为负债。

### ⚙️ 设置
- **账本管理**：新建 / 切换 / 改名 / 删除账本。
- **数据备份**：导出备份、导入备份、载入示例数据、清空所有数据。
- **关于**：隐私与数据说明。

> 记账入口不放在右上角，而是收在「日历当天明细」和「账户详情」里，避免误触。

## 核心概念

### 账本（books）
数据隔离的最上层单位。记录（`bookId`）和账户（`bookId`）都归属于某个账本，切换账本后看到的日历、统计、资产都是那个账本的数据。

### 账户（accounts）
隶属于账本，字段包括名称、图标、余额、备注。
- 余额为正数是资产，负数是负债。
- 编辑余额时会生成一条「余额调整」记录，方便追溯。
- 至少需要两个账户才能转账。

### 记录（records）
有四种类型：

| 类型 | 说明 | 是否计入收支统计 |
| --- | --- | --- |
| `income` | 收入 | ✅ |
| `expense` | 支出 | ✅ |
| `transfer` | 账户间转账，只改变两个账户余额 | ❌ |
| `adjust` | 手动调整账户余额 | ❌ |

转账和调整只影响账户余额，不计入当天的收入 / 支出 / 结余，也不出现在趋势和统计里。

### 分类（categories）
分支出、收入两套，可自定义名称、图标、颜色。旧记录按记账时的分类名归集，改名 / 删除分类不影响历史记录。

## 数据存储与隐私

- 数据保存在浏览器 `localStorage`，键名 `qingzhangben_v1`。
- **默认状态是空的**：新打开没有任何账户和记录，资产页会提示「还没有账户」。想体验图表可在设置里点「载入示例」。
- 不上传服务器、不含账号体系、没有网络请求。清除浏览器数据会导致账本丢失，建议定期「导出备份」。
- 导入备份会覆盖当前全部数据，请谨慎操作。

## 技术实现

- **单文件**：`轻账本.html`（约 140 KB），包含全部 HTML 结构、CSS 和 JavaScript。
- **无框架 / 无构建**：原生 JS，用一个状态对象 `S` 存持久化数据、一个 `ui` 对象存临时界面状态；通过 `render()` 重绘视图，用事件委托（`data-action`）统一处理点击。
- **手写 SVG 图表**：环形占比图、折线趋势图、资产趋势图都是直接用 SVG 拼出来的，没有引入图表库。
- **发布**：通过资料库 Page 发布为在线短链（见文首链接）；本地改动不会自动同步到线上，需要重新导入并发布。

## 常见问题

- **为什么我打开是空白的？** 默认就是空白账本，先在「资产」里点「＋ 添加」建账户，再去日历里点某一天记账即可。
- **手机上怎么用？** 直接用手机浏览器打开在线链接，底部导航切换页面；数据存在这台设备的浏览器里。
- **换设备 / 换浏览器数据还在吗？** 不在。需要用「导出备份」把数据带过去，再在新设备「导入备份」。
- **别人能看到我的账吗？** 不能。数据只在你自己的浏览器里，分享链接给别人，他们看到的是空白账本。
